TUgas 5 Pemweb

1. Pengertiap Bootsrap
   Bootstrap adalah alat yang membantu kita membuat tampilan website dengan lebih mudah dan cepat. Did dalamnya sudah ada berbagai bentuk tampilan, seperti tombol, menu, dan susunan halaman, jadi kita tidak perlu membuat semuanya sendiri dari awal. Bootstrap juga membantu website menyesuaikan tampilan saat dibuka di hp maupun komputer.

2. Memasang Bootstrap
   Ada beberapa cara untuk menggunakan Bootstrap, pertama bisa memasukkan link bootstrap ke dalam file HTML, jadi bootstrap bisa langsung digunakan, lalu bisa juga didownload dan memasukkanya kedalam project, dan yang terakhir menggunakan npm untuk memasang.

3. Grid dan Breakpoint
   Grid digunakan untuk mengatur posisi isi website supaya lebih rapi. contonya menyusun 3 gambar secara berdampingan.
   Sementara, breakpoint digunakan untuk menyesuaikan susunan website berdasarkan ukuran layar. misalnya 3 gambar yang tadi berjajar di PC bisa berubah menjadi kebawah saat dilihat dari tampilan hp

4. Class Bootstrap
   .container = mengatur isi website
   .row = menyusun isi dalam 1 baris
   .col = membagi ruang menjadi beberapa bagian
   .btn = membuat tombol
   .text-center = membuat tulisan berada di tengah

5. Gambar responsif
  Supaya ukuran gambar dapat menyesuaikan layar hp dan komputer, bisa menggunakan class "img-fluid"
    "<img src="foto.jpg" class="img-fluid" alt="Foto">"
